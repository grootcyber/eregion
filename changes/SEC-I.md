### Security
- **The enquiry before a decision reads the VM the registry names, never a host name a line carries; the memory of past decisions weighs the VM and the rule, one precedent per VM** (SEC-I, #850; `docs/glorfindel.md`, the enquiry and the memory; `docs/design/correlation.md`; `docs/design/modele-de-menace.md`, section 4). The six enquiry queries are scoped by the resource id of the VM the detection was routed to, never by the host name of the line, which root on any host of the workspace chooses: a host named like the VM no longer writes the context the model reads. A detection attributed to no VM runs no enquiry query (said, counted as not run). The correlation no longer falls back on the host name: a row without its resource id names no VM, and stays a card.
  - The memory keeps each past cycle's VM and rule in its metadata, ranks the cycles of the same rule, then of the same VM, before the distance of the text, and gives at most one precedent per VM, the signal's own included, reading past a VM at its bound — past the cycles stored before this change, which name no VM, the whole memory is read, nothing stored rewritten: a flood of one VM's cycles no longer fills every place. The VM of a detection attributed to none is never stored. Each cycle is stored as not corroborated; the retrieval does not filter on it yet. What the model reads is the same, to the byte, for the same precedents.
  - Tests: `tests/unit/test_enquiry_memory.py`; mutants M5821–M5839 (`scripts/mutants/SEC-I.py`).

### Fixed
- **The shipped rule on blob writes counts written writes only; the shipped rule on writes under the system's logs no longer drops an audit event a forged record joins** (SEC-I, #850; `docs/azure.md`, `docs/operations.md`, « La mesure au banc des deux règles de SEC-I »). A blob write the storage account refused (a non-2xx code) no longer counts, nor puts a card on the VM that holds the caller's address; the limit of an application relay is written in the rule. A known writer of logs is set aside only on an audit event of one SYSCALL record of its key, counted distinct: a second record, written at the event's serial, makes it a card; a line the agent delivers twice does not. Both rules are measured on the bench before merge.
  - Tests: `tests/unit/test_enquiry_memory.py` (the shipped rules run as written on placeholder lines).
