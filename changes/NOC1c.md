### Changed
- **The night runs on the subscription, the CLI's claude.ai login, never on an API key** (NOC1c, #1276; `docs/sessions.md`, « La nuit »). An `ANTHROPIC_API_KEY` set in the shell for Glorfindel passes before that login, and in `-p` the key is always used when present: the night would be billed on it, up to the pass's cap. The night's unit now carries, in its `[Service]` section, `UnsetEnvironment=` with every variable among the sources Claude Code ranks before the login (its documentation, « Authentication precedence », and the cloud providers' `CLAUDE_CODE_USE_*` its environment variables page names): `ANTHROPIC_API_KEY`, `ANTHROPIC_AUTH_TOKEN`, the providers' selectors, and the Anthropic profile and federation variables; and `ANTHROPIC_BASE_URL` and `ANTHROPIC_CUSTOM_HEADERS`, which are not keys but would route the pass's calls through a gateway or carry an authentication header. `CLAUDE_CODE_OAUTH_TOKEN`, a subscription's token, stays. `install.sh` refuses a settings file the pass reads (`~/.claude/settings.json`, the repository's `.claude/settings.json` and `.claude/settings.local.json`, and the night's own `--settings` file) that sets one of those variables, even empty, or an `apiKeyHelper`, naming the key, never its value; it says an Anthropic profile on disk (`~/.config/anthropic/configs/`), which no variable unsets; and it refuses a `claude` taken from an editor's extension (the `extensions/` of a `.vscode*`, `.cursor*` or `.windsurf*` directory, wherever it is, or a link into one), whose path changes at each update of the extension, and says to install the CLI apart (`~/.local/bin/claude`). `DRY_RUN=1` shows the unset line and says each refusal without refusing. The unit's `PATH` names each directory once, `~/.local/bin` first. The documentation names what the unit cannot unset (an active profile, a gateway's session, the managed settings), and how to check the login once without the model (`claude auth status --text`, the unit's variables unset) and watch its end.
  - Tests: `tests/unit/test_night_unit.py`. Mutants M8207–M8211 and M8220–M8224 (`scripts/mutants/NOC1c.py`).
