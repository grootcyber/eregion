### Fixed
- **The 360°'s vault satellite counts what the RECOVER block counts, and never says 0 when it does not know** (SAT1, #1271; Jonathan, on Imladris; `docs/design/console.md`, « Le satellite d'un coffre »). On Imladris it said « 0 protected » and drew no line, while the RECOVER block said « 2 protected »: the 360° read an inventory item's name raw — Azure's `VM;iaasvmcontainerv2;<rg>;<vm>` — where the block reads its last part. Both read it the same way now. An inventory not read yet, or in error with nothing good kept, is no longer taken as empty: the satellite says « not read yet » or « read error », its card says so with the error, no line is drawn and no VM is said unprotected.
  - Tests: `tests/unit/test_console_vault_sat.py`; mutants M8171–M8174 (`scripts/mutants/SAT1.py`).
