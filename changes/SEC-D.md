### Security
- **The threat model names two more boundaries: the watch's Microsoft Graph read and the Stratus binary** (SEC-D, #636; security audit of 06/11, P-02; `docs/design/modele-de-menace.md` §5, `docs/design/orodruin-contract.md`). The watch's Graph read (IR1a): four read-only application permissions, set by hand outside Terraform, that apply to the whole tenant and, on H0, to the watch, the console and the bot, which share the VM's identity; what holds it (a GET-only reader, the console never reading Graph, no write permission ever, nothing by default) and what stays open (no start-up contract re-reads the watch's Graph rights; planned: SEC-B, #634, and V-28). The Stratus Red Team binary launched from Orodruin (R2a): what holds it (closed catalog allow-list, pinned sha256 re-checked before every phase, each phase journaled and counted under the cap from an armed contract, enrolled bench group in zone `bench` only, offline Terraform) and what stays open (no target input, Orodruin's environment and identity inherited, so its reach is Orodruin's RBAC; the binary is not shipped yet; planned: R2b, #608, then R2c). H0's line no longer says its identity holds « nothing else » without naming Graph.

### Changed
- **`SECURITY.md` follows the supported line: 0.5.x, then 0.6.x** (SEC-D, #636; audit P-03). It said « latest 0.4.x ». Each new minor version now updates the table in its own version pull request (`docs/sessions.md`, « Le cycle d'une release »).
- **`docs/architecture.md` describes what was missing** (SEC-D, #636; audit P-04): the correlation before the decision (a diagram, `glorfindel/correlation.py`), the watch's key and its three signed uses (heartbeat, detections, the action queue's proposals and receipts) with the signed action queue behind its flag (a diagram), the identities and the identity executor (disabled by default, no verb yet), the bot and the Graph read in the processes diagram; the console's token is no longer called optional; Stratus Red Team is described as merged (R2a), not as future.
- **`scripts/setup.sh` removed** (SEC-D, #636; audit P-06): an orphan script, referenced nowhere, that installed the dependencies without the lock file nor their hashes. `make install` installs from `requirements/dev.txt`, with `--require-hashes`.
