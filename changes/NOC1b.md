### Changed
- **The night's guard covers the whole invariant machine: the journal, the hold, the frozen sequences and the nights' watchdog** (NOC1b, #1269; `docs/sessions.md`, « La nuit »). The pattern `tests/unit/test_invariants*.py` (with an « s ») left out `test_invariant_journal.py`, `test_invariant_hold.py`, `test_invariant_regressions.py`, `test_invariant_regressions_aws.py` and `test_invariant_watchdog.py`, and `tests/unit/invariant_watchdog.py` was not listed: a night could weaken one of them and merge it without the maintainer. The pattern is now `tests/unit/test_invariant*.py`, and `invariant_watchdog.py` joins the list, each a question for the maintainer (his decision of 27/11, regressions included). Two neighbours join them: `tests/unit/hypothesis_seed.py`, the seed the invariant nights draw (SEED1), which a night could change to escape a failing seed, and `tests/unit/test_night_unit.py`, the tests of the night's own unit beside `scripts/night/`. The machine's companions are held by their prefix (`fake_azure*`, `fake_aws*`, `invariant_hold*`, `invariant_watchdog*`, `hypothesis_seed*`), since a package or a link of the same name would hide the module from the machine's relative imports; and so are the seed's tests (`tests/unit/test_hypothesis_seed.py`), every `__init__.py` under `tests/`, and every compiled module (`*.pyc`, `*.pyo`, `__pycache__/`), which an unchecked-hash `.pyc` added with `git add -f` would use to replace its source. A test walks the closure of the machine's relative imports and fails until each module it reaches is held: a day session that adds a companion adds it to the guard. The night no longer freezes a new sequence on its own: its pull request stays open, unmerged, and the morning's report proposes it. A neighbour outside the machine (`test_investigate.py`) is not caught.
