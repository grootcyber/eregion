### Fixed
- **The Orodruin contract's Stratus guarantees now gate only an arming for a Stratus run, so a bench `orodruin.env` that names the dedicated Stratus subscription no longer turns Gothmog, an Annatar VM run or the drill passive** (ORG1, #1003; `gothmog/README.md`, « Reste, sur le banc, avec Jonathan »; `eregion_core/orodruin.py`, `annatar/executors/stratus_host.py`, `annatar/runner/engine.py`). Found at the bench (G1, 20/11): once `EREGION_STRATUS_SUBSCRIPTION` was set in `orodruin.env`, the contract judged the two Stratus guarantees — the dedicated identity's closed role (`read_stratus`) and the sandbox that blocks the IMDS (`read_sandbox`) — at **every** arming. ORO_RUN_GOTHMOG mounts neither the federated assertion nor the sandbox proof, so both read unreadable and the run turned passive before any call to the cloud, though Gothmog runs no Stratus. `check()` and `arm()` now take `for_stratus`: the base contract (orodruin-check, Gothmog, an Annatar VM run, the drill) is the current readers minus the two Stratus guarantees and never requires them; only `check(for_stratus=True)` / `arm(..., for_stratus=True)` — the run that mounts the assertion and the proof — asks for them. The Annatar engine arms `for_stratus=scenario.engine == "stratus"`.
  - **The scoping cannot fail open.** A Stratus phase runs only from a session armed with the guarantees: `StratusExecutor._before_call` refuses (`Passive`) a base-contract session — Gothmog, a VM run, or a Stratus arming that forgot the flag — before the first injector call, and the guard reads the flag with a `False` default so a session object lacking it is refused too (fail closed by omission, never by a present `True`). The session is marked at arming; the base set is derived from the current readers at check time (a swap of a reader is honoured, never a stale snapshot).
  - Tests: `tests/unit/test_orodruin.py` (the guarantees gate only a Stratus arming; the base set follows the current readers; `arm` judges them only for Stratus and marks the session; a bare `Session` is not `for_stratus`) and `tests/unit/test_annatar_stratus.py` (the executor refuses a base-contract session and one missing the flag; the engine arms `for_stratus` iff the scenario's engine is `stratus`).
