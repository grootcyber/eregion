### Changed
- **The watch leaves the header: said where Glorfindel is drawn, the return channel where its runs are** (HRT1, #1272; `docs/design/console.md`, « La watch quitte l'en-tête »). Jonathan's choice (27/11). The shared header no longer says the watch's beat nor the return channel; it keeps the model breaker's pill and the clock. The watch is said at the 360°'s heart, under the table's GLORFINDEL, in the overview's GLORFINDEL row and on Dagorlad's GLORFINDEL card — one reading told to each place at the same second: one age, one server's `since`, a missed beat seen alike everywhere. Dagorlad says the console's reading. Where the runs are, V1 is said at the head: when the gate refuses a run, Dagorlad's GLORFINDEL card opens on « ● no live watch for a run » in red, then why in the gate's own words, then the watch and the return channel. The return channel stays in the overview's CHANNELS row and joins Dagorlad's GLORFINDEL card; an age it was not given reads « age unknown », never 0 s nor NaN; the Glorfindel page no longer says it. The Runs view (`/dagorlad?view=runs`) gets a GLORFINDEL line at its head, in the Board card's words: V1, the watch, the return channel, read from `/api/channel?gate=1`. The gate is a fresh, uncached read of the heartbeat, as a run makes it, so the route says it only when asked: the overview, which polls it for its CHANNELS row, never pays it. After a read that failed, the next one redraws the line even when its answer did not change. A board that fails to load no longer wipes Glorfindel's card: the watch and the return channel stay, V1 then asked of `/api/channel?gate=1`. A phone keeps each in its place.
