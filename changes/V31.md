### Security
- **The control-plane injector's execution host is hardened on three fronts** (V31, #889). (1) The environment handed to the third-party binary and to Terraform is now **minimal** — only the toolchain and the (non-secret) Azure scope are inherited from the host; every other variable (the model key, the watch keys, the channel URLs) is dropped, so no secret reaches the subprocess (`annatar/executors/stratus_host.py`, `_INHERITED_ENV`, `_env`). (2) A technique runs only when the catalog marks it `implemented` (reviewed, ready to test) or `proven` (measured at the bench); a `planned` entry (design only) is refused before resolution, so it never reaches a run with the identity's rights (`annatar/engines/stratus.py`, `_require_runnable_status`, `resolve`). (3) The subscription id and the resource-group name are held to their Azure shapes before they enter the ARM path read for the enrollment guard, so a name carrying a `/` or `..` cannot steer the read to another group's tags (`annatar/executors/stratus_host.py`, `_validate_arm_ids`).
  - Tests: `tests/unit/test_annatar_stratus.py` (the subprocess env drops a host secret and keeps the scope; a `planned` technique is refused and a `proven` one resolves; a malformed group name and a non-GUID subscription are refused before the ARM read). Mutants M6021 (the full host env passed again), M6022 (the status gate bypassed), M6023 (the group name unvalidated), M6024 (the subscription unvalidated), `scripts/mutants/V31.py`.
