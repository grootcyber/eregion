### Changed
- **The Stratus control-plane injector is now BUILT from a vendored submodule, not downloaded** (R2BW, Partie de #608). Stratus is vendored as a git submodule at `annatar/stratus/stratus-red-team/` — the **official** `DataDog/stratus-red-team` repository pinned to the commit of tag `v2.38.1` — and `make stratus-build` (`scripts/stratus_build.py`, replacing `scripts/stratus_stage.py`) **builds** the binary from that source with our in-repo patch applied (`CGO_ENABLED=0 go build -trimpath`, pinned Go), instead of fetching the published release binary. Provenance becomes ours (a reproducible build: the pinned commit + the patch + the recorded sha256 in `annatar/stratus/PIN`, re-checked before every phase, SEC5 unchanged), which lets us upgrade when we choose and carry the bastion SKU fix ahead of upstream. Terraform and the azurerm/azuread providers stay official HashiCorp downloads, verified against the PIN, their versions **read from the submodule** (`TerraformVersion`, the techniques' `required_providers`) as the single source of truth.
  - Our change lives in the repo, not a fork: `annatar/stratus/patches/bastion-sku.patch` (`create-bastion-shareable-link`: `Standard_F2` → `Standard_D2as_v7` + Gen2 image `2022-datacenter-g2` — only target-template SKUs, no offensive logic rewritten, so the "no home-grown offensive logic, pinned public library" invariant holds). The submodule is a build input, excluded from the injector image (`.dockerignore`); the built binary is never committed (`annatar/stratus/staged/` gitignored, the image `COPY`s it).
  - Tests: `tests/unit/test_stratus_build.py` (the build + verify + fail-closed layout, hermetic: a fake submodule, injected build/fetch — no network, no real `go build`), `tests/unit/test_annatar_stratus.py` (the committed PIN digest is the built binary's). Mutants M5681–M5682, `scripts/mutants/R2BW.py` (the reproducibility guard, the divergent-provider-pin guard); R2BS's M5386/M5387 and R2BV's M5671 re-anchored onto the new file/digest (`scripts/mutants/R2BS.py`, `scripts/mutants/R2BV.py`).
  - Docs: `docs/design/stratus-cible.md` (the submodule + build provenance model), `docs/design/modele-de-menace.md` (frontier E: the binary's provenance is now ours, compensated by the pinned commit + reproducible build + minimal patch).
