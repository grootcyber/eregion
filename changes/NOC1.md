### Added
- **The night's Orchestre, prepared: each night fixes what main turned red, and cuts a release draft in the morning** (NOC1, #1251; `docs/sessions.md`, « La nuit »). A `night` mode of the elrond skill: one pass around 05:30 UTC, after main's night workflows, that stops at once while a version PR is open or a freeze is noted; reads what went red on main since the day before, from scheduled and push runs on a commit of `origin/main` only (never a fork's pull request), the jobs before any log, cause by cause (a surviving mutant, an invariant sequence, a flaky test, a CVE, another defect); takes three at most, each through a neutral issue, a worker, an Opus 5.5 review, the verdict posted, a green CI, the night's guard, `check`, then the merge, with a single attempt per cause; then, when main is green and holds fragments, the version PR, the release gate, its review and merge, and `make release-draft` — never a publication; and ends with its report on Discord, the Orchestre's state rewritten and the plan updated. The freeze rule is written: during a freeze everything goes on, only the merges wait, and the PRs reviewed « ok » merge in the train's order after the version PR.
  - **The night's guard**, `scripts/night_guard.py`, run from `origin/main` (never from the branch it judges). First what the CI did (`--pr N`): in the log of the PR's own CI run on its head (never a fork's) and of main's push run on the commit that CI merged into, for each « lint + tests » job, pytest's summary lines and `mutant_anchors.py`'s count — the tests collected may not go down, the skipped and xfailed not up, the mutants and the control set not down, a line unread is a refusal. Then what the diff says: what a branch brings over its merge base with `origin/main`, refused without Jonathan (exit 1, a reason a line; 2 when it cannot be read) when it removes or renames a `test_*` function of a collected file (a file or a class that leaves pytest's patterns takes its tests out); adds a skip, a skipif, an xfail, an importorskip, a `skipTest`, `__test__`, `collect_ignore*`, `pytestmark`, a collection hook, `del test_…` or an emptied `parametrize`, read on the syntax tree through the imports' aliases and tied to the test it sits in; removes a mutant (the lots' files selected as the harness does), changes its `new` without its `old`, changes its file, moves it into CONTROL, or adds or changes its reason (`EQUIVALENT:`, `TIMING:`, `MULTI-HOST:`); touches `.github/`, `requirements/`, a `.terraform.lock.hcl`, a `conftest.py`, `pytest.ini`, `tox.ini`, `setup.cfg`, `pyproject.toml`'s dependencies, entry points, build, pytest or ruff settings, or adds a module at the repository's root; touches an invariant's oracle (`tests/unit/test_invariants*.py`, `fake_azure.py`, `fake_aws.py`, `invariant_hold.py`) or the mutation's harness (`scripts/mutation_check.py`, `scripts/mutant_anchors.py`, `scripts/mutants/*.json`); changes a named threshold of `test_file_sizes.py`, `test_docs_budget.py`, the read budgets or `french_ceiling.json`, in either direction; or touches the night's own rails (`.claude/`, `scripts/night/`, the guard, `scripts/review_verdict.py`). A lot's mutants file is read once its syntax tree passes an allowlist, by a child given the harness's own `RENAME`, with a bare environment under limits: no sandbox, and said so. Its output never carries a review's key. A day session may use it too.
  - **The scheduled task, prepared and not installed**, `scripts/night/`: a systemd `--user` service and its timer at 05:30 UTC (`Persistent=false`), running `claude -p "/elrond night"` at the repository's root under `flock`, `NoNewPrivileges`, a five-hour bound, `--permission-prompts none`, the deny rules of `scripts/night/settings.json` (force-push, a push to main or of a tag behind `git -C` too, `gh api` writes, `--admin` and `--auto`, a release published, a workflow run, Terraform, Azure, the bench, Imladris, the product's CLIs and the harness, the secrets' files by Read and by Bash, the night's rails in a worktree too) and a `--max-budget-usd` cap; `install.sh` (`install`, `uninstall`, `status`, `DRY_RUN=1`), refused in an agent session and in a lot's worktree, and never with `bypassPermissions`; `make night-install`, `night-uninstall`, `night-status`. The permission mode is the maintainer's decision: the options of Claude Code's documentation are written down, `auto` recommended.
  - **The full mutation measure every night**, a patch for the maintainer to apply (`scripts/night/mutants-nightly.patch`): `mutants.yml` from Monday to every night at 23:41 UTC; what it and `mutants-night.yml` each cover is written down.
  - Tests: `tests/unit/test_night_guard.py`, `tests/unit/test_night_unit.py`; mutants M8018–M8029, M8032–M8045, M8053–M8062.
