### Security
- **Imladris's CD deploys only a release under a `v<semver>` tag a rule of the repository reserves, at the commit the repository's API names** (SEC-G, #848; `infra/glorfindel-host/README.md`, « Le CD d'Imladris »; `docs/sessions.md`, « Les règles du dépôt »; `docs/design/modele-de-menace.md`, §6 and §7). Before anything is fetched, a tag that is not `v<major>.<minor>.<patch>` is refused. A tag no active rule reserves is refused, where it was only said; a rule that does not read holds the release, said once. With the rule of the repository's tags extended to every tag (the maintainer's gesture), no identity but his can create a tag, hence publish a release: that is what holds, not the release's author, which the CD does not read (the sessions' App drafts every release, the maintainer publishes it). The tag's commit is read on the repository's API (an annotated tag followed): an origin that names another commit is refused. The way back asked on Imladris follows the same rule. `deploy.sh` and `make imladris-start` take a commit by its 40 characters only, never a prefix.
  - Tests: `tests/unit/test_host_cd.py` (a release under « 0.4.1 », a tag the API names otherwise, no tag rule, a release the App drafted deploys), `tests/unit/test_host_deploy.py` (mutants M5761–M5778 but M5763, M5764 and M5768, `scripts/mutants/SEC-G.py`).
- **The SSH source toward Imladris and Orodruin is one public IPv4 address, in /32** (SEC-G, #848; `infra/glorfindel-host/README.md`, `infra/orodruin/README.md`). `OPERATOR_CIDR`, or the third-party service's answer when it is unset (said, never suffixed in silence), passes `scripts/operator_cidr.py` before any plan; both modules' validation refuses a range, an IPv6, a private, shared or reserved address. The value is never expanded by make and stays off the command line shown.
  - Tests: `tests/unit/test_operator_cidr.py`, `infra/glorfindel-host/tests/operator_cidr.tftest.hcl`, `infra/orodruin/tests/channel_journal.tftest.hcl`.
- **Every read, write and delete on Orodruin's channel is journaled** (SEC-G, #848; `infra/orodruin/README.md`). A diagnostic setting of the channel account's blob service sends `StorageRead`, `StorageWrite` and `StorageDelete` to the bench's workspace, where no identity admitted to the channel can delete them. Applied at the maintainer's next `make orodruin-lock`.
- **The manual tunnel to Imladris's console reads no SSH configuration and listens on the loopback only** (SEC-G, #848). `make imladris-tunnel` runs as the workstation's systemd tunnel does: `-F none`, `-L 127.0.0.1:7007:127.0.0.1:7007`, the host key pinned, `ExitOnForwardFailure`; its key comes from the SSH agent or `HOST_SSH_KEY`.
  - Tests: `tests/unit/test_host_console.py`.
- **The images' base is proposed for a bump every week, and a High or Critical CVE fixed upstream in their system packages is judged** (SEC-G, #848; `docs/operations.md`, « Les images publiées »). Dependabot proposes the digest of `python:3.12-slim` for both Dockerfiles in one pull request (`.github/dependabot.yml`), never another Python version. `scripts/image_cves.py` installs grype pinned by its archive's sha256 and refuses a report that holds such a CVE, or that saw no distribution. No `apt-get upgrade` at build: an image stays what its digest says. The release gate's job that runs it comes with the workflow's own change.
  - Tests: `tests/unit/test_image_cves.py`.
