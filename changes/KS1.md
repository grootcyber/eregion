### Security
- **A campaign whose kill switch cannot be read stops** (KS1, #648; `docs/operations.md`). Before each run, `annatar campaign run` re-reads its manifest's `kill_switch` through the bounded reader of `runs/` (SEC-A1). A manifest the reader refuses (a pipe, a link, a file too large) or that cannot be read (not JSON, nested too deep, an I/O error, a `kill_switch` that is neither true nor false) now stops the campaign (`aborted`, exit code 1) instead of letting it continue: the reason is said once in the runner's output and recorded in the manifest as `stop_reason`. A manifest that is absent still asks for no stop. A kill switch set by the operator is recorded the same way (`stop_reason: "kill switch set"`).
  - Tests: `tests/unit/test_campaign_runner.py`. Mutants M4573–M4575.
