### Added
- **The Relaxed view shows the expected origins, in force only while the watch's switch is on** (CFG3c, #1154; `docs/design/configuration-console.md`, §6). Each entry of `network_zones.expected_origins` the strict reading keeps and `classify` classes as relaxing is a line of the view (`expected_origin`, « expected origin » in the console): its object, its path in the file, what it designates (the range, or the named network and what the discovery wrote of it, no Azure read), no reason, author « unknown ». The watch, the only reader of `GLORFINDEL_LATERAL`, writes the switch in the view: on, the line is in force and says what the code does (a `ssh-brute-force` detection from it set aside before any signal, said and counted, no card, never blocked); off, the line stays, « without effect », never shown active, nor a named network only it cites. An unknown value of the switch is said. The switch is part of what the view is computed from: changed at the watch's restart, the view is computed again. The console shows « in force » only when the watch wrote it; `expected_origin_count` is unchanged.
  - Tests: `tests/unit/test_relaxed_view.py`; mutants M7400–M7407 (`scripts/mutants/CFG3c.py`).
