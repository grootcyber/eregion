### Changed
- **The elrond cycle keeps the maintainer's steering manual up to date at every step** (MAN0, #640 ; `docs/sessions.md`, « Le manuel de pilotage » ; `.claude/skills/elrond/SKILL.md`). The main session updates the lot's brick (state, PR, what it waits for, timestamp) and adds a line to the feed when it launches a lot, receives it, reviews, merges and prepares a release; after a release is published, the bricks on `main` become delivered with their version and the next release becomes the one being assembled. At `/elrond status` it compares the manual with the plan and GitHub (open PRs, merges since the last tag, tags, closed issues, last release), catches up the gap and says so in the feed. The manual is private: no link, identifier or address of it goes into the repository; its address stays in the main session's local memory. An unreachable manual never holds a lot back.
