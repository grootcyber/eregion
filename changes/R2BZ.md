### Fixed
- **The hardened execution host lets Terraform providers execute, from a dedicated exec tmpfs** (R2BZ, part of #608). On an armed Orodruin the injector container is `--read-only` with `--tmpfs /tmp` mounted `noexec` (the hardening); Terraform, during the warmup, extracts the provider plugins under the run HOME and EXECUTES them — so the first real bench run failed with `fork/exec … permission denied`. A dedicated `--tmpfs /stratus-home:exec` (`ORO_EXEC_HOME`) is now added **only to the annatar run defs** — those that may run the control-plane library (`ORO_RUN`, `BENCH_ORO_RUN`, `ORO_RUN_REQUEST`) — and the injector builds the run HOME there (`annatar/executors/stratus_host.py`, `EXEC_HOME`). Only the provider location is executable; `/tmp` stays `noexec`; the shared `ORO_HARDEN` is **unchanged** (so Orodruin stays hardened exactly as docker-compose, and the control/gothmog/contract runs never get the exec mount). Absent the mount (a test, a non-container run), the default temp dir is used.
  - Tests: `tests/unit/test_annatar_stratus.py` (the run HOME lands on the exec tmpfs when present and falls back otherwise; the exec tmpfs is on the annatar runs only, never on `ORO_HARDEN` nor the gothmog/contract runs). Mutants M6081 (the tmpfs mounted noexec) + M6082 (the HOME ignores it), `scripts/mutants/R2BZ.py`.
