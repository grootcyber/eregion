### Fixed
- **The hardened execution host lets Terraform providers execute, from a dedicated exec tmpfs** (R2BZ, part of #608). On an armed Orodruin the injector container is `--read-only` with `--tmpfs /tmp` mounted `noexec` (the hardening); Terraform, during the warmup, extracts the provider plugins under the run HOME and EXECUTES them — so the first real bench run failed with `fork/exec … permission denied`. `ORO_HARDEN` now also mounts a dedicated `--tmpfs /stratus-home:exec`, and the injector builds the run HOME there (`annatar/executors/stratus_host.py`, `EXEC_HOME`): only the provider location is executable; `/tmp` stays `noexec` and the rest of the hardening (read-only root, `--cap-drop ALL`, `--security-opt no-new-privileges`) is unchanged. Absent the mount (a test, a non-container run), the default temp dir is used.
  - Tests: `tests/unit/test_annatar_stratus.py` (the run HOME lands on the exec tmpfs when present and falls back otherwise; `ORO_HARDEN` mounts the exec home and keeps `/tmp` noexec). Mutants M6081 (no exec tmpfs) + M6082 (the HOME ignores it), `scripts/mutants/R2BZ.py`.
