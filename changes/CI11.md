### Fixed
- **The jobs that install Terraform refresh HashiCorp's apt source alone** (CI11, #728 ; `.github/workflows/ci.yml`, `release-gate.yml`, `canary-azurerm.yml`). On 11/11, Ubuntu's mirrors did not resolve for hours on GitHub's runners (`security.ubuntu.com`, in a window: `main` and the canary were green on the same image just before), and a pull request's `terraform-test` failed twice on `apt-get update -o APT::Update::Error-Mode=any`, its code nothing to do with it. CI's `terraform-test`, the release gate's `terraform` and the azurerm canary now refresh `/etc/apt/sources.list.d/hashicorp.list` alone (`Dir::Etc::sourcelist`, `Dir::Etc::sourceparts=-`): an outage of Ubuntu's mirrors no longer fails them, and `Error-Mode=any` still holds for HashiCorp's index. No image is pinned: the image was not the cause.
  - Tests: `tests/unit/test_workflows.py` (each job that installs Terraform, found by what it runs — HashiCorp's apt repository, or `apt-get install … terraform` — and no other, refreshes that source alone). Mutants M4814–M4815 (`scripts/mutants/CI11.py`).
