### Changed
- **The enquiry's readings come from a closed catalogue, out of `glorfindel/agent.py`; the message to the model is unchanged to the byte** (ENQ2, #1064; `docs/architecture.md`, « L'enquête, et son catalogue de lectures » ; design: `docs/design/enquete-raisonnee.md` §4, §13). `glorfindel/enquiry/catalog.py` holds the six queries of `investigate`, their text unchanged, each with its id, its sentence for the model, the parameters the code fills (the registry's VM, the detection's address, each a checked KQL literal), its window (its query's `ago()`, counted from the moment the read runs, not from the signal's hour: anchoring it on the signal comes with ENQ4), its declared latency, its author (the guest, provocable or forgeable) and what it can say under Linux and under Windows (the Process counter says nothing under Linux). A read's outcome takes one of seven states, never confused: rows, empty, without object, pending, failed, refused, not permitted. `glorfindel/enquiry/fixed.py` keeps today's routing on the detected row's columns and runs the reads through the catalogue: the same queries in the same order, the same rows for the model (`[]` for any read that returned none), the same gaps for the telemetry guard of `decide` (a read that failed or was not run). The dossier takes its Windows-only reads from the catalogue. The form is written to take the dossier's readings (DOS4) and a new type of object later, each entering only once measured. `glorfindel/agent.py` slimmed by 179 lines (its ceiling lowered to 3562, WCH1).
  - Nothing the model sees changes: the prompt, the user message, the few-shot examples and the decision tool are untouched; on fixed signals (Linux and Windows, a failure, a refusal, an unattributed detection), the message, the KQL sent and the gaps are frozen by their sha256, measured before the change. No end-to-end run is required.
  - Tests: `tests/unit/test_enquiry_catalog.py`; the tests that patched the enquiry's runner in `glorfindel.agent` patch `glorfindel.enquiry.fixed.run_query`. Mutants M7095–M7099 (`scripts/mutants/ENQ2.py`); the ten mutants anchored in the old code of `investigate` (M153, M1311, M1312, M1322, M1324, M1379, M1380, M5821–M5823) follow it, the same fault at its new place, all caught.
