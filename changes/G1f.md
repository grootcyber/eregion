### Fixed
- **vm-cpu-pressure reads the CPU as the Linux agent names it** (G1f, part of #76; `gothmog/experiments/vm-cpu-pressure.yaml`). The DCR declared the CPU under its Windows name, which the Linux agent never collects, so G1b's preflight refused the fault on 20/11. After DCR1 (#985) was applied on gondolin, the CPU arrived on 21/11 under `Processor` / `% Processor Time` with the instances `total`, `cpu0` and `cpu1`. The effect's query now reads the aggregate `total`, not Windows' `_Total`. The preflight no longer refuses the fault for its series, and the fault stays `planned` until its first measured run on the bench.
  - Tests: `tests/unit/test_gothmog_noise.py` (the query names what arrived, and the DCR declares `\Processor(*)`) and `tests/unit/test_gothmog_readiness.py` (a Perf holding only the measured instances: the preflight lets the fault run). Mutants M6952–M6953, `scripts/mutants/G1f.py`.
