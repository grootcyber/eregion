### Added
- **The enquiry in production, behind `GLORFINDEL_ENQUIRY`, `fixed` by default** (ENQ5b, #1284; `docs/design/enquete-raisonnee.md` §5, §6, §7, §9.6, §9.7; `docs/raisonnement.md` §10.4; `docs/operations.md`, « L'enquête en production »). `fixed`, the default: today's enquiry and decision, the message `_build_user_message()` writes, `_SYSTEM_PROMPT`, `_DECISION_TOOL` and `few_shot_examples.yaml` identical to the byte to origin/main's (their sha256 on fixed Linux and Windows signals), and a cycle loads nothing of the loop. Any other value — and `GLORFINDEL_ENQUIRY_T_S` (5 to 120) or `GLORFINDEL_ENQUIRY_N` (1 to 8) out of their bounds — is refused at the start: the watch does not start, and says why. `loop`: `investigate` runs the loop of ENQ4 on what the watch knows — the registry's VM, its system read once by the discovery in the VM's model (`osType` of its OS disk, never `OSType` of `Heartbeat`), the configuration's vault, the sheet by rule then technique, the last enquiry on the same VM and rule; each KQL query noted on the `LOG_ANALYTICS` budget, never refused nor delayed, each read of the vault taken on `ARM` before it runs (refused: `refusee`, a gap when obligatory). `decide` then reads the sheet, every read with its state among seven and the last enquiry on the object (after the VM's present state, never in place of a read of today); the decision tool gains an optional `hypotheses` field, each citation checked by the code (a read not done, not served or in a state that carries no verdict proves nothing; the code's predicate wins). The telemetry guard holds on the code's reads failed, refused or, obligatory, still waiting — never a `sans_objet`, a `non_permise`, a read the model asked nor a read not served; its card says each gap with its state. The floor V-11 is extended: on a grave technique, a decision that does not contain makes a card that proposes `isolate_vm`, whatever the model cites, never run by it, stepping behind the ceiling's or B3a's card. The gate reserves the enquiry's N + 1 turns and counts them when the decision ends; a turn refused by the breaker sends `decide` to the code's path. The memory per object is written by the watch at the end of the cycle (`~/.glorfindel/enquiry/references/`), read for its own object only, its human verdict read on its card. The card says each hypothesis of the sheet, its state, its verdict on the cycle and what settled it. T = 30 s and N = 4 are kept on the measure of 24/11, to recalibrate at the end-to-end run. `loop` is switched on Imladris only after the maintainer's end-to-end run (T1486, then T1548.003), joined to MEM2. The read « who writes » (WRT1) stays to be measured: neither `investigate` nor `decide` runs it.
  - Tests: `tests/unit/test_enquiry_production.py`; `tests/unit/test_enquiry_loop.py`, `tests/unit/test_enquiry_knowledge.py` (the bridge of production, imported only by the switch); mutants M8266–M8285 and M8303 (`scripts/mutants/ENQ5b.py`); M2918 re-anchored.

### Fixed

The first beat of the window gets its start as predecessor, the end is added as the last beat, a window without a beat answers its gap — and the end is never T bare: the lag of the VM's last beat ingested is taken off the moment the query runs, so beats that come late never read as an agent cut. `investigate`'s own text, in `fixed`, is unchanged.
