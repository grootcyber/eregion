### Added
- **`make orodruin-run SCENARIO=<name> [DRY_RUN=1]` — play one scenario on an armed Orodruin, in one guarded command** (ORU1, part of #608). Until now a single scenario on the execution host was a hand-typed ssh + `docker run`; this target does it, with the **same session guard as `make bench-run`** (a code session never launches an attack — `scripts/orodruin_run.py`, `bench_shared.session_refusal`): the scenario name is validated and the guard runs before any ssh. `DRY_RUN=1` shows what would happen without a cloud call; `WITHOUT_GLORFINDEL=1` is a dev run (V1). The run itself stays the operator's gesture.
  - Tests: `tests/unit/test_makefile_orodruin_run.py` (the recipe + the guard, hermetic — no make, no ssh). Mutants M6041 (the session guard bypassed) + M6042 (`DRY_RUN=1` would run for real), `scripts/mutants/ORU1.py`.
