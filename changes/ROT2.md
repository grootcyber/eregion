### Security
- **The console token of Imladris now turns in one command, typed on the workstation, and `#deploy` reminds to turn it again 90 days later** (ROT2, #968; `docs/operations.md`, « Faire tourner le jeton de la console d'Imladris »; `infra/glorfindel-host/README.md`; `docs/design/modele-de-menace.md`, §1). Before, the console of Imladris read `EREGION_CONSOLE_TOKEN` from `host.env`, drawn once by `make imladris-env` (which never overwrites a `host.env`), and `make console-rotate` refuses a token the deployment sets: nothing ever turned it, and it stayed in the browser's and the terminal's history, the phone's included. `make imladris-console-rotate` (`scripts/console_rotate.py`) is refused in a code session and when Imladris is not within reach (its host key pinned), then refuses a `host.env` that is missing, unreadable or without a console token, before anything. It draws a new token, in the form `make imladris-env` draws, and rewrites the token's line alone: under `EREGION_CONSOLE_TOKEN`, at its place, a line of the former name, `GLORFINDEL_WARROOM_TOKEN`, replaced when it carried the token and removed otherwise; every other line stays to the byte, line endings included. The file is written beside it in 0600, checked as `make imladris-push` checks it (`host_env.py --check`), then renamed over the old one; that temporary file is ignored by git. It is pushed by `make imladris-push`, which pushes the local `glorfindel-config.yaml` too (as it always does: the operator checks it first), the console alone is recreated (`docker compose up -d --no-deps --force-recreate war-room`: the watch and the bot do not move) under the lock of the deployments that Imladris's CD holds for its pass — held, the restart is refused and said —, and the console is probed on Imladris as `make imladris-status` probes it, the tokens on curl's standard input: the new one must answer and the old one, as compose hands it to the console (quotes removed), be refused, its sessions with it. The token is never printed nor put on a command line; `make imladris-url` reads it again. The day to turn it again, the draw plus 90 days (`DAYS=…`), is noted on Imladris by ROT1's path under its own name, `console-token`, a name and a date; Imladris's CD reminds in `#deploy` at J-14, J-7, J-1 and on the day, with the exact command — a reminder, the console still takes the token after. `make imladris-console-token-note` notes the token in place, counted as drawn today, without turning it. A push or a restart that fails says so and leaves `host.env` coherent, the new token on the workstation: the command is typed again. The agent of the CD changes (`eregion_cd.py`, the token among the reminders): `make imladris-cd-install` after the merge, and an agent from before is said by the command, the date noted anyway.
  - Tests: `tests/unit/test_console_rotate.py` on a fake `ssh` and `scp` toward a fake Imladris, whose fake `docker` makes the console read its `.env` again and whose fake `curl` answers as the console does, the real CD agent installed there, and one run of the whole `make imladris-console-rotate` through the real `make imladris-push`, from a copy of the checkout, its host key pinned by a throwaway key (mutants M6656–M6672, `scripts/mutants/ROT2.py`).
