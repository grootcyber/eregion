### Fixed
- **A block written whole again says anew its perimeter pair still on an NSG the customer took off the subnet, once the operator had acknowledged the card that said it** (REL068b, the 0.6.8 release gate, #1209; `docs/design/reaffirmation.md`). A VM was blocked on its subnet and for itself, and the customer took the subnet's NSG off. The reassertion said so on a card of the block (`perimeter_off`) and marked the pair said for that NSG. The operator acknowledged the card, and the VM was then blocked again. A block written whole is a new block and a new episode, so the write drops the marks of the cards said before it (L1Q). It kept this one, and every pass after read the pair as already said: still named, still gone, and nothing said again. The write now drops that mark with the others. The pair is still never put back, since the NSG taken off is the customer's (E7).
