### Added
- **The NSG audit gives each network interface's public IPs** (IPS1a, part of #931; `docs/azure.md`, « L'IP publique de chaque carte, dans l'audit »). Each entry of `nsgs[]` in `check_nsg_access` — the audit the console reads through `/api/audit` — now carries `public_ips`: a list, empty when the NIC has no public IP, one element per public IP of its IP configurations, `{"address": "<address>"}`, or `{"address": null, "error": "<reason>"}` when the read failed. Each address is read once per call, read-only, by `publicIPAddresses.get` in the IP's own resource group, taken from its id (`glorfindel/providers/azure/public_ips.py`). A read that fails never fails the audit: the « NSG access » check stays `ok`, and the element says why — refused (a 403), not found, not allocated yet (a dynamic IP on a stopped VM), or Azure's first line otherwise, without any id. `dry_run` is unchanged; nothing else in the shape changes. The watch's identity on its host holds Reader on the bench's resource group only: a public IP in another group is said refused. Known limit: a VM with no NSG on its NIC nor on its subnet still fails the audit, so its address is not read. The page that shows it comes with the console's part of the lot.
  - Tests: `tests/unit/test_public_ips.py` (no public IP, one, two IP configurations with one public, a 403 with the NSG check still `ok`, another resource group, no address, not found, throttled, read once per call, the reason without an id, `dry_run`), on the in-memory Azure (`tests/unit/fake_azure.py`, which now holds public IP resources). Mutants M6421–M6430, `scripts/mutants/IPS1a.py`.
