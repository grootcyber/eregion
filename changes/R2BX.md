### Changed
- **`make stratus-build` builds in a pinned `golang` container by default — no local Go required** (R2BX, Partie de #608). R2BW's build ran a local `go`; on a workstation without Go (the usual case — the bench builds via a container), it failed with `PermissionError: 'go'`. `scripts/stratus_build.py` now builds the injector binary inside `golang:1.26` **pinned by digest** (`GO_IMAGE`, the exact image — go1.26.11 — the pinned sha `834976c9…` was built with), run as the operator (`--user`, so the temp source stays user-owned and cleans up), CGO off + `-trimpath` (user/path independent). `EREGION_GO=<path>` still forces a local `go` binary (which must be go1.26.11 to reproduce the pinned sha). The reproducibility guard (the built sha must match the PIN) is unchanged.
  - Tests: `tests/unit/test_stratus_build.py::test_docker_build_argv_is_reproducible_and_pinned` (the command pins the toolchain by digest and stays reproducible — hermetic, builds nothing). Mutants M5691 (image pinned by tag not digest) + M5692 (`-trimpath` dropped), `scripts/mutants/R2BX.py`.
  - Docs: `annatar/stratus/PIN` (the default container toolchain + the `EREGION_GO` override), `docs/design/stratus-cible.md`.
