Manuel d'Eregion

lecture du manuel…

L'état du projet, composant par composant : chaque brique est un module, sa couleur dit sa pièce, sa forme dit son état. Le manuel est un fichier du dépôt, mis à jour par la pull request de chaque lot ; l'état des pull requests et des issues est relu sur GitHub au chargement.

Un lot de sécurité n'y paraît que sous un titre neutre, sans constat ; ni geste de l'opérateur, ni relecture ; aucune note sur ce qui n'est pas encore livré.

La route

De la première release au CDR prouvé

Une étape par release ; chacune liste les briques qu'elle pose.

    La source : docs/manuel/modules.yaml, que la pull request de chaque lot met à jour ; une release passe les briques sur main en livrées, avec leur version. L'état des pull requests, des issues et de la dernière release est lu dans l'API publique de GitHub, sans jeton ; si elle ne répond pas, la page montre ce que dit le dépôt.
